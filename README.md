# Анализ трат

Учебный проект: простой сайт, который анализирует траты пользователя за разные периоды. Пользователь вручную добавляет расходы и видит итог, разбивку по категориям, графики и сравнение с предыдущим периодом. Есть светлая и тёмная темы.

**Статус: сайт реализован, идёт ручная проверка по чек-листу.**

## Что умеет

- Добавление, редактирование и удаление трат: сумма, категория, дата, комментарий.
- Выбор периода: неделя, месяц, год или свой диапазон дат, переход к предыдущему/следующему периоду.
- Сводка: итог за период, средний расход в день, главная категория, изменение к прошлому периоду.
- Кольцевая диаграмма по категориям и столбики по дням или месяцам.
- Список категорий с суммами и долями, таблица трат за период.
- Демо-данные одной кнопкой в пустом состоянии.
- Светлая и тёмная темы с запоминанием выбора.
- Хранение данных в `localStorage` браузера.

## Ограничения

- Только фронтенд: HTML, CSS, чистый JavaScript. Без фреймворков, сборки и установки пакетов.
- Сайт работает без интернета и без локального сервера: открывается двойным кликом по `app/index.html`.
- Один пользователь, без регистрации.
- Валюта — рубли, фиксированный список категорий.
- Графики рисуются собственным SVG-кодом, сторонние библиотеки не используются.

Подробнее — в [плане](docs/plan.md).

## Запуск

Откройте `app/index.html` двойным кликом в браузере (Chrome, Edge или Firefox). Ни сервер, ни `npm install` не нужны. Данные хранятся в `localStorage` браузера.
