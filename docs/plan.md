# План: сайт «Анализ трат» (учебный проект)

## Цель
Одностраничный сайт без сервера: пользователь вручную добавляет траты, выбирает период (неделя / месяц / год / свой диапазон) и видит итог, разбивку по категориям, графики и сравнение с предыдущим периодом. Светлая и тёмная темы.

## Принятые решения
- Только фронтенд: HTML + CSS + чистый JS, без сборки и зависимостей. Открывается двойным кликом по `index.html` (значит, **без ES-модулей**, обычные `<script defer>` в нужном порядке).
- Данные — в `localStorage`, один пользователь, без авторизации.
- Ввод вручную; в пустом состоянии кнопка «Заполнить примерами» (демо-данные). Загрузка CSV — в будущем, см. «Расширение».
- Валюта — рубли, формат `1 234 ₽`; суммы храним в копейках (целое), чтобы не было ошибок округления.
- Фиксированный список категорий: Еда, Транспорт, Жильё, Развлечения, Здоровье, Одежда, Подписки, Прочее.
- Графики — самописные SVG (столбики + кольцевая диаграмма), без Chart.js и интернета.
- Вне области: доходы, лимиты бюджета, аккаунты, синхронизация, мультивалюта.

## Файлы
```
index.html
css/styles.css
js/store.js      — категории, localStorage, CRUD, демо-данные
js/periods.js    — границы периодов, агрегация, сравнение
js/charts.js     — SVG-графики и форматирование чисел
js/app.js        — рендер, обработчики, темы
```
Порядок подключения: `store.js` → `periods.js` → `charts.js` → `app.js`.

## Данные
```js
// ключ localStorage: budget.transactions.v1
{ id: "uuid", amountKopecks: 45250, category: "food",
  date: "2026-11-17", note: "Обед" }  // note может быть ""

// ключ localStorage: budget.theme  → "light" | "dark"
```
- `CATEGORIES`: id, подпись, цвет (цвета заданы CSS-переменными, чтобы работали в обеих темах).
- Хранилище: `load()`, `save(list)`, `add()`, `update(id, patch)`, `remove(id)`, `seedDemo()`; при битом JSON — сброс к пустому списку без падения.
- Демо-набор: 12–15 трат за последние ~3 месяца, разные категории и суммы (чтобы сразу были видны все графики).

## Экран
1. **Шапка**: заголовок «Анализ трат», переключатель темы (кнопка с иконкой, `aria-pressed`), на мобильных — в строку.
2. **Панель периода**: вкладки `Неделя | Месяц | Год | Свой период`; для первых трёх — стрелки ← → и подпись диапазона («Ноябрь 2026», «11–17 ноя», «2026»); для своего — два `<input type="date">` и проверка `начало ≤ конец`, даты не в будущем.
3. **Карточки сводки**: «Итого за период», «Средний расход в день», «Больше всего — категория», «К прошлому периоду: +12% / −8%» (рост трат — красный).
4. **Графики**: кольцевая диаграмма по категориям с легендой (сумма и доля %) + столбики по дням (для недели/месяца) или по месяцам (для года/длинного своего периода). При отсутствии данных — заглушка, а не пустой прямоугольник.
5. **Список категорий**: горизонтальные полосы с суммой и процентом от итога.
6. **Таблица трат** за период: дата, категория (цветной чип), комментарий, сумма, кнопки «Изменить»/«Удалить» (подтверждение удаления). Сортировка — новые сверху.
7. **Форма добавления** (сверху или сбоку): сумма (обязательна, > 0, до копеек), категория (select), дата (по умолчанию сегодня, не в будущем), комментарий ≤ 100 символов. Ошибки — текстом под полем, по-русски. При редактировании та же форма в режиме «Сохранить/Отмена».
8. **Пустое состояние**: пояснение + «Добавить трату» + «Заполнить примерами» (вторая кнопка — только когда данных нет).
9. Адаптив: одна колонка ≤ 720px; карточки 2×2 на планшете.

## Логика периодов и расчётов
- Неделя — пн–вс вокруг выбранной даты; месяц и год — календарные; свой период — включая обе границы.
- «Прошлый период»: предыдущая календарная единица для недели/месяца/года; для своего периода — такой же по длине интервал непосредственно перед ним.
- Итог = сумма `amountKopecks` с датой в границах; доля категории = сумма категории / итог; средний в день = итог / число календарных дней периода.
- Форматирование: `1 234,50 ₽`; для осей графика компактно `12,5 тыс.`; проценты с одним знаком; пустой результат — `0 ₽`.
- Часовой пояс не учитываем: даты — строки `YYYY-MM-DD`, сравнение строковое.

## Темы
- CSS-переменные на `:root[data-theme="light"|"dark"]` (фон, поверхность, текст, сетка, 8 цветов категорий).
- Начальная тема: сохранённая в `localStorage`, иначе `prefers-color-scheme`; выбор сохраняется, применяется до первой отрисовки, чтобы не было вспышки.

## Порядок работ
1. `index.html`: каркас страницы, семантические блоки, подключение стилей и скриптов.
2. `css/styles.css`: токены тем, сетка, карточки, форма, таблица, чипы, адаптив.
3. `js/store.js`: категории, чтение/запись localStorage, CRUD, демо-данные.
4. `js/periods.js`: границы периодов, предыдущий период, агрегация по категориям и по дням/месяцам, сравнение.
5. `js/charts.js`: кольцевая диаграмма, столбики с осями и подписями, форматирование сумм.
6. `js/app.js`: состояние (период, тема, режим формы), рендер сводки/графиков/списков/таблицы, обработчики, валидация, пустое состояние, переключение темы.
7. Ручная проверка по чек-листу, правка мелочей.

## Проверка (ручной чек-лист)
- Добавление траты сразу обновляет сводку, графики, таблицу; данные видны после перезагрузки.
- Сумма `0`, отрицательная, пустая, текст — блокируются с понятным сообщением; сумма с копейками принимается.
- Дата в будущем не принимается; свой период с `начало > конец` — ошибка.
- Переключение неделя/месяц/год/свой диапазон меняет подпись, итог и график; стрелки ← → работают.
- Сравнение с предыдущим периодом считает верно (проверить на демо-данных вручную).
- Редактирование и удаление траты корректно меняют все отчёты.
- Тема переключается, сохраняется после перезагрузки, оба варианта читаемы (контраст текста).
- Нет данных — видны заглушки, нет ошибок в консоли; график не ломается при одной категории и при очень больших суммах.
- Работает при открытии `index.html` напрямую (без локального сервера), в Chrome/Edge/Firefox.
- Вёрстка не разъезжается на 360px и 1440px.

## Критерии готовности
Сайт открывается без сервера и интернета, позволяет вести траты, показывает сводку, категории, два графика и сравнение с предыдущим периодом за неделю/месяц/год/свой диапазон, переключает и запоминает тему, корректно ведёт себя на пустых и крайних данных.

## Расширение (не делать сейчас)
CSV-импорт: добавить в `store.js` метод `importRows()` с тем же объектом траты и отдельный разбор файла; экраны и аналитика не меняются.
