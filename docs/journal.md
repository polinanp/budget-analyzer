# Журнал проекта

Хронология работы: что сделано, какими файлами, как проверено и что дальше. Записи добавляются после каждого этапа, сверху — свежие.

## Как вести журнал

Для каждого этапа добавлять блок:

```
## ГГГГ-ММ-ДД — название этапа

Статус: сделано / в работе / отложено

Сделано:
- ...

Файлы:
- ...

Проверка:
- ...

Дальше:
- ...
```
